## 📝 文档规范说明

### 命名规范

所有文档遵循统一命名格式：
```
{编号}-{Family标识}-{阶段}-{模块}-{文档名称}.md
```

示例：`001-AI-Family-启动规划阶段-项目章程与愿景.md`

> **注意**: 元数据中的 `FAMILYcategorycategory` 字段名存在拼写重复错误，应修正为 `FAMILYcategory`。

### 版本规范

采用语义化版本号 (SemVer)：`主版本.次版本.修订版本`

- **主版本**: 架构重大变更或不兼容更新
- **次版本**: 功能新增或向下兼容变更
- **修订版本**: Bug修复或内容优化

### 标签规范

使用方括号包裹标签，支持多标签：`[标签1],[标签2],[标签3]`
