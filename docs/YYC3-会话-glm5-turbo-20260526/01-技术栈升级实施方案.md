# 🚀 技术栈升级实施方案

## 方案概述

> **目标**: 将 YYC³ Smart Service Engine 从当前技术栈升级至最新稳定版本，确保项目长期竞争力和安全性。
>
> **核心升级项**:
> - Next.js: **14.2.25 → 16.2.6** (跨2个大版本)
> - TypeScript: **5.7.3 → 6.0.3** (大版本升级)
> - Tailwind CSS: **^3.4.17 → 4.3.0** (大版本升级)
> - Radix UI: 全量小版本更新

---

### 1.1 环境检查 ✅

```bash

node --version  # 应该显示 v18.x 或更高
```

```bash
git checkout main
```

### Phase 2: 类型修复与适配 (Day 2-3)

#### Step 2.1: 常见TypeScript 6.0 迁移问题及解决方案

**问题1: any类型警告升级为错误**

```typescript
// ❌ 之前 (TS 5.7 允许)
const data: any = fetchData()

// ✅ 之后 (TS 6.0 要求明确类型)
interface FetchData {
  id: string
  name: string
}
const data: FetchData = fetchData()
```

**问题2: Promise泛型更严格**

```typescript
// ❌ 之前
async function getData() {
  return await fetch('/api/data')  // 隐式返回Promise<any>
}

// ✅ 之后
interface ApiResponse<T> {
  data: T
  status: number
}

async function getData(): Promise<ApiResponse<User[]>> {
  const response = await fetch('/api/data')
  return response.json()
}
```

**问题3: React类型更新**

```typescript
// ❌ 之前
import React from 'react'
import type { FC } from 'react'

// ✅ 之后 (React 19 + TS 6)
import type React from 'react'
// 直接使用内置类型，无需额外导入FC
```

#### Step 2.2: 批量修复脚本

创建 `scripts/fix-ts6-types.ts`:

```typescript
#!/usr/bin/env tsx
/**
 * TypeScript 6.0 自动化修复辅助脚本
 * 用于批量处理常见的类型迁移问题
 */

import * as fs from 'fs'
import * as path from 'path'
import { glob } from 'glob'

interface FixResult {
  file: string
  fixesApplied: number
  errors: string[]
}

async function fixTypeScriptFiles(): Promise<FixResult[]> {
  const files = await glob('**/*.{ts,tsx}', {
    ignore: ['node_modules/**', '.next/**', '**/*.test.*', '**/*.spec.*']
  })
  
  const results: FixResult[] = []
  
  for (const file of files) {
    const result = await fixSingleFile(file)
    results.push(result)
  }
  
  return results
}

async function fixSingleFile(filePath: string): Promise<FixResult> {
  let content = fs.readFileSync(filePath, 'utf-8')
  let fixesApplied = 0
  const errors: string[] = []
  
  try {
    // Fix 1: 替换显式any为unknown（需要手动完善）
    if (content.includes(': any')) {
      content = content.replace(/: any/g, ': unknown // TODO: fix type')
      fixesApplied++
    }
    
    // Fix 2: 更新React导入
    if (content.includes("import React from 'react'") && !content.includes("import type React")) {
      content = content.replace(
        "import React from 'react'",
        "import type React from 'react'"
      )
      fixesApplied++
    }
    
    // Fix 3: 移除不必要的FC类型
    if (content.includes(': React.FC')) {
      content = content.replace(/: React.FC</g, '<')
      fixesApplied++
    }
    
    // 写回文件
    fs.writeFileSync(filePath, content, 'utf-8')
    
  } catch (error) {
    errors.push(`Error processing file: ${error}`)
  }
  
  return {
    file: filePath,
    fixesApplied,
    errors
  }
}

// 执行修复
fixTypeScriptFiles().then(results => {
  console.log('\n📊 TypeScript 6.0 Migration Results:')
  console.log('=' .repeat(50))
  
  const totalFixes = results.reduce((sum, r) => sum + r.fixesApplied, 0)
  const filesWithFixes = results.filter(r => r.fixesApplied > 0).length
  
  console.log(`✅ Files processed: ${results.length}`)
  console.log(`🔧 Files modified: ${filesWithFixes}`)
  console.log(`📝 Total fixes applied: ${totalFixes}`)
  
  const errorResults = results.filter(r => r.errors.length > 0)
  if (errorResults.length > 0) {
    console.log(`\n⚠️  Files with errors: ${errorResults.length}`)
    errorResults.forEach(r => {
      console.log(`  - ${r.file}: ${r.errors.join(', ')}`)
    })
  }
  
  console.log('\n💡 Next steps:')
  console.log('  1. Run: pnpm typecheck to identify remaining issues')
  console.log('  2. Manually review and fix unknown types')
  console.log('  3. Run tests to ensure no regressions')
})
```

运行修复脚本：

```bash

pnpm add -D tsx glob

# 执行自动修复
npx tsx scripts/fix-ts6-types.ts

# 检查结果

```

### Phase 3: Tailwind CSS v4 迁移 (Day 4-6) ⚠️ 可选延后

#### Step 3.1: 理解 Tailwind CSS v4 核心变化

**配置方式变革**:
```
Tailwind v3: JavaScript配置 (tailwind.config.js)
Tailwind v4: CSS-first配置 (@theme指令)
```

**新的CSS配置方式** (`app/globals.css`):

```css
/* ❌ Tailwind v3 方式 */
@tailwind base;
@tailwind components;
@tailwind utilities;

/* ✅ Tailwind v4 方式 */
@import "tailwindcss";

@theme {
  /* 自定义颜色 */
  --color-primary: #3b82f6;
  --color-secondary: #64748b;
  
  /* 自定义字体 */
  --font-sans: 'Inter', ui-sans-serif, system-ui;
  
  /* 自定义间距 */
  --spacing-72: 18rem;
  --spacing-84: 21rem;
}

/* 自定义组件样式 */
@utility btn-primary {
  @apply inline-flex items-center justify-center rounded-md bg-primary px-4 py-2 text-sm font-medium text-white shadow-sm;
}
```

```bash
git push origin main --force-with-lease
```

### 3.2 回滚决策标准

**立即回滚条件** (满足任一即回滚):
- ❌ 生产环境构建失败
- ❌ 超过50%的测试用例失败
- ❌ 关键业务功能不可用
- ❌ 性能下降超过30%

**评估后回滚条件**:
- ⚠️ 10-50%测试失败（评估修复成本）
- ⚠️ 性能下降10-30%（评估影响范围）
- ⚠️ 大量非关键性breaking changes
