4. **标准对标严格**: 完全遵循 YYC³ 五高五标五化五维体系，确保输出物符合规范

### 遇到的挑战及解决方案

**Challenge 1**: useIsMobile Hook 测试失败
- **原因**: jsdom 环境缺少 `window.innerWidth` 的真实值
- **解决方案**: 使用 `Object.defineProperty` mock window.innerWidth
- **学习**: React Hooks 测试需要仔细模拟浏览器环境

**Challenge 2**: 组件目录差异判断
- **发现**: ui/ 和 components/ui/ 内容不完全相同
- **决策**: 选择保留 components/ui/ (更完整，有额外6个组件)
- **依据**: components.json 配置指向 @/components/ui

**Challenge 3**: 中文变量名导致错误
- **现象**: .eslintrc.json 中的中文变量导致 NameError
- **修复**: 使用转义或避免在 JSON 配置中使用中文作为变量名

### 最佳实践沉淀

1. **工具链优先**: 先建立 DevOps 基础设施，再进行代码修改，可自动保证质量
2. **测试先行**: 在重构前先写测试，可大幅降低引入 bug 的风险
3. **文档同步**: 每次重大变更都更新文档，保持文档与代码一致
4. **增量验证**: 每步都运行 build/test，而非最后统一验证
