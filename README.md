## �🚀 快速开始

### 📋 前置要求

| 工具 | 版本要求 | 推荐版本 |
|------|----------|----------|
| Node.js | >= 18.x | 20.x LTS |
| pnpm | >= 8.x | 9.x |
| Git | >= 2.x | Latest |

### 📦 安装步骤

```bash
# 克隆仓库
git clone https://github.com/YYC-Cube/YYC3-Smart-Service-Engine.git
cd YYC3-Smart-Service-Engine

# 安装依赖 (推荐使用 pnpm)
pnpm install

# 启动开发服务器
pnpm dev

# 在浏览器中打开 http://localhost:3000
```

### ⚡ 可用脚本

| 命令 | 描述 | 说明 |
|------|------|------|
| `pnpm dev` | 启动开发服务器 | http://localhost:3000 |
| `pnpm build` | 构建生产版本 | 输出至 .next/ 目录 |
| `pnpm start` | 启动生产服务器 | 预览构建结果 |
| `pnpm lint` | 运行 ESLint 检查 | 代码规范验证 |
| `pnpm lint:fix` | 自动修复 ESLint 错误 | 自动格式化 |
| `pnpm format` | 使用 Prettier 格式化 | 代码美化 |
| `pnpm test` | 运行测试 | 监听模式 |
| `pnpm test:run` | 运行所有测试 | 单次执行 |
| `pnpm test:coverage` | 生成覆盖率报告 | 覆盖率统计 |
| `pnpm typecheck` | TypeScript 类型检查 | 严格模式验证 |

## 🤝 贡献指南

我们欢迎所有形式的贡献！请阅读 [CONTRIBUTING.md](CONTRIBUTING.md) 了解详细的贡献流程。

### 📝 Commit Message 规范

项目遵循 [Conventional Commits](https://www.conventionalcommits.org/) 规范：

```
<type>(<scope>): <subject>

<body>

<footer>
```

**类型 (type)**:

- `feat`: 新功能
- `fix`: Bug 修复
- `docs`: 文档更新
- `style`: 代码格式调整
- `refactor`: 代码重构
- `test`: 测试相关
- `chore`: 构建/工具链变更
- `perf`: 性能优化

**示例**:

```bash
feat(ai): add enhanced context management with memory system
fix(hooks): resolve race condition in concurrent API calls
test(components): add VoiceInterface component tests (100% coverage)
docs(readme): update installation guide for Node.js 20 LTS
perf(build): optimize Turbopack configuration for faster HMR
```
